# Functions that read a keyboard or click modifier outside the keymap.
# `<path from crates/blyg-app/src> <fn> | <class> | <reason>`, one per line.
# Classes: guard (only rejects or ignores modified keys), mouse (a click or
# scroll modifier), `chord <keys>` (handles its own chord, keys in keymap
# spelling as a Mac user presses them), mac-only. Checked by
# `src/key_handlers_tests.rs`. A `chord` the keymap also binds needs
# `shares <context>` in its reason: the keymap binds it in <context>, and the
# line says why the handler is never live there (or that it is unchecked).
# A new shortcut belongs in keymap.rs, where the Windows tests see it.
